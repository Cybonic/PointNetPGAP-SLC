# Loop Closure Visualization Using Predictions

## Overview

This script (`plot_loop_closure_pr_gif.py`) generates animated GIFs showing loop closure detection frame-by-frame using **model predictions** instead of ground truth data.

## Key Changes from Ground Truth Version

### 1. **New Class: `LoopClosureVisualizerPredictions`**
   - Uses model predictions loaded from `predictions.pkl` files
   - Supports configurable **top-K** predictions
   - Includes **distance threshold** filtering

### 2. **Parameters**

#### Required Input
- `predictions`: Dictionary loaded from `predictions.pkl` with structure:
  ```python
  {
    query_idx: {
      'pred_loops': {
        'idx': array([...]),      # Predicted neighbor indices
        'dist': array([...]),     # Descriptor distances
        'segment': array([...])   # Segment labels
      },
      'true_loops': {...},
      'segment': int
    }
  }
  ```

#### Configurable Parameters
- **`topk`**: Number of top predictions to visualize (default: 1)
- **`distance_threshold`**: Maximum distance in meters for valid loop closures (default: 10.0)
- **`sample_rate`**: Show every N-th query frame (default: 10)

### 3. **Prediction Loading**

The script automatically finds and loads prediction files from the structure:
```
saved/hortov2/
  ├── SEQUENCE_NAME/
  │   ├── MODEL_NAME/
  │   │   ├── predictions/
  │   │   │   ├── place/
  │   │   │   │   ├── <metric>@<K>/
  │   │   │   │   │   ├── predictions.pkl
```

### 4. **Visualization Features**

- **Red star**: Current query frame
- **Green circles**: Predicted loop closure matches (within distance threshold)
- **Green lines**: Connections to matched frames
- **Blue trajectory**: Path traveled up to current frame
- **Info boxes**: 
  - Frame statistics (top-left)
  - Predicted distances (top-right)

### 5. **Title Updates**
- Shows "PREDICTIONS" to distinguish from ground truth
- Displays current top-K setting
- Shows distance threshold used

## Usage

### Basic Usage
```bash
python plot_loop_closure_pr_gif.py
```

### Customizing Parameters

Edit the configuration section in the script:

```python
# Sequences to process
SEQUENCES = ["PCD_EASY", "PCD_Easy_DARK", "PCD_MED", "PCD_RAS_EASY"]

# Models to visualize
MODEL_NAMES = [
    "PointNetPGAP-None",
    "PointNetVLAD-None",
    "SPVSoAP3D-SoAP-log-pnl-fc-None",
    "LOGG3D-None",
    "overlap_transformer-None"
]

# Visualization parameters
TOPK = 1                    # Show top-1 prediction
DISTANCE_THRESHOLD = 10.0   # 10 meters max distance
SAMPLE_RATE = 10            # Show every 10th query frame
```

### Custom Top-K and Range

To visualize **top-5** predictions with **15-meter** threshold:

```python
TOPK = 5
DISTANCE_THRESHOLD = 15.0
```

### Faster/Slower Animation

Modify the sample rate:
```python
SAMPLE_RATE = 5   # More frames (slower, more detailed)
SAMPLE_RATE = 20  # Fewer frames (faster, less detailed)
```

## Comparison: Predictions vs Ground Truth

| Feature | Ground Truth (`plot_loop_closure_gif.py`) | Predictions (`plot_loop_closure_pr_gif.py`) |
|---------|-------------------------------------------|---------------------------------------------|
| Data source | Computed from trajectory positions | Loaded from model predictions |
| Top-K | Not applicable | Configurable (1, 5, 10, etc.) |
| Distance filtering | Applied during GT computation | Applied during visualization |
| Multiple models | No (one GT per sequence) | Yes (one GIF per model) |
| Title | "Loop Closure Detection" | "Loop Closure Detection (PREDICTIONS)" |
| Info shown | Frame ID, Label, Neighbor count | + Top-K, Distance threshold |

## Prediction File Structure

The script expects predictions saved in the following format (generated by the evaluation pipeline):

```python
predictions = {
    query_idx: {
        'segment': np.uint8,              # Query segment label
        'pred_loops': {
            'idx': np.array(dtype=uint32),    # Predicted neighbor indices
            'dist': np.array(dtype=float32),  # Descriptor distances (NOT spatial!)
            'segment': np.array(dtype=uint8)  # Neighbor segment labels
        },
        'true_loops': {
            'idx': np.array(...),
            'dist': np.array(...),
            'segment': np.array(...)
        }
    }
}
```

**Note**: The `'dist'` in predictions represents descriptor similarity distances, not spatial distances. The script filters by spatial distance after retrieving predicted neighbors.

## Troubleshooting

### Error: "Predictions directory not found"
- Check that predictions have been generated for the sequence/model
- Verify the `PRED_ROOT_DIR` path is correct

### Error: "No predictions.pkl found"
- Ensure evaluation has been run with `save_predictions=True`
- Check the predictions directory structure

### Warning: "No predictions available!"
- The predictions file is empty or has no query frames
- Verify the evaluation completed successfully

### GIF has very few frames
- Increase `SAMPLE_RATE` to show fewer frames
- Some sequences may have limited query frames after warm-up

## Tips

1. **Start with low sample rate** (e.g., 20) for quick previews
2. **Use top-K=1** for cleaner visualizations
3. **Adjust distance threshold** based on dataset characteristics
4. **Process one model at a time** for faster iteration
5. **Check prediction files exist** before running
